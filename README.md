* **Developed Kinnect**, a social media application that allows users to sign up, log in, view posts, send and accept friend requests, view their friends list, upload and view stories, browse chats, message friends, and make voice calls.
* **Built the frontend UI** using Android LinearLayout and RelativeLayout.
* **Integrated Firebase as the backend** to store user registration credentials, posts, friend lists, stories, and chat history.
* **Implemented Firebase Cloud Messaging (FCM)** to deliver real-time push notifications.
